# 桌面新版修复的 Bug 清单

整理来源：桌面「新版本卫戍协议」项目的 `CHANGELOG.md`（版本 0.3.0、0.3.1），截至 2026-10-18。这里列的是更新记录明确写为修复、修正或解决的项目；只增加功能的内容不列入。部分条目是按官方规则纠正实现，不一定属于玩家报告的故障。

## 战斗与规则

- **联防漏怪计算**：联防中新生成的分裂/召唤子代不再计入原漏怪者的生命扣减和顶栏漏怪数量；服务器校验客户端上报的子代标记，异常时拒绝并重算。
- **攻击出手后的目标追击**：远程干员出手后目标仍在射程内时，弹道会追踪完成；敌人攻击出手后也会完成本次攻击。眩晕等控制仍可打断。
- **突袭落点**：按敌人身体而非仅所在格判断落点，隐秘核心中偏移后的「假想敌：管」附近可正确落地。
- **野鬃二技能推人方向**：敌人在野鬃身后且即将离开当前格时，推力沿攻击方向，不再反向推向蓝门。
- **瑕光二技能**：现在可攻击技能范围内、陷入沉睡的地面敌人，不受朝向限制。
- **风丸替身对空**：替身形态可攻击空中单位；二技能召唤物仍按官方规则不能对空。
- **干员射程边缘**：干员射程按敌人碰撞半径判定；碰撞圈进入射程格即可索敌，原有阻挡、溅射及「所在格」判定不变。
- **枯朽之种自毁**：改为可被逻各斯三技能减速、清除的飞行弹道，飞行期间不可选中。
- **假想敌：镜膜**：首次被沉默后永久失去生命值加成；法抗仍在沉默结束后恢复，模型也切换为停转状态。
- **悬赏投石机三连击**：拆成三次独立物理攻击，分别触发受击效果并各自溅射，不再被当成一次攻击处理。
- **贾维赠送与合成**：首次刷新凑齐三只拉普兰德并合成精锐时，不再吞掉已有干员「首次主动刷新」叙拉古层数。
- **临时整备区溢出**：超过可见格的棋子和装备排队保留，格位腾出后补入；悬赏、特质、策略发放和退回装备不再因内部容量上限被销毁。
- **库存耗尽后的已展示奖励**：装备在商店/奖励出现后，即使公共库存被其他玩家拿空，已展示的卡仍可购买或领取；后续刷新会扣除欠账，避免继续超发。
- **奖励选择超时/不可发放**：不可发放的奖励不再消耗选择；超时选择会跳过不可用项。
- **定向投放奖励覆盖商店**：晋升、定向投放等奖励出现时，商店中的棋子和装备卡一并让位；选择稍后后恢复原商店，不再出现卡片重叠或误买。
- **凯瑟琳突变细胞**：定向投放可刷出突变细胞；每局领取上限得到处理，已领取后后续或排队奖励不再重复出现，未领取的仍可再次刷出。
- **维多利亚等盟约激活奖励**：未激活时已达门槛的维式重锤/资金，在盟约激活瞬间补发，不必等到休整期结束；每档仅发一次。
- **琳琅诗怀雅三技能**：0.3.1 改为满 10 金币后不自动关闭、不消耗金币、不推敌。这是官方规则更正，不是一般意义上的崩溃类 Bug。

## 联机、大厅与对局状态

- **公开状态推送节奏**：推送间隔从实际广播时刻计算，避免延迟或排队时重复/过密推送。
- **合作战场初始镜头**：只有一名博士协防时，联防开始镜头正确对准该玩家所在半场。
- **插件公告和主题身份**：编辑公告或主题值不再错误改变房间内容/外观身份，也不再误报插件已变更；大公告不会吞掉其他插件公告。
- **插件房间规则冲突**：相互冲突的插件规则会点名拒绝，不会静默覆盖；规则进入内容哈希，避免房间客户端玩法不一致。
- **插件交互窗口**：非阻塞窗口可以收起并恢复整备；无效奖励不消耗选择，超时跳过不可用选项；测试跳隐藏关时正确初始化队伍生命。
- **自选编队私有卡池**：新版同盟模拟中的自选干员私有库存翻倍，其商店出现概率不再被扩大的公共卡池稀释。

## 画面、动画与音效

- **官方场景材质**：修正 3D 棋盘场景偏暗、材质发灰/平淡的问题；水面使用正确材质参数，有场景地板时不再叠画错误的活性源石色块。
- **官方特效挂点与弹道**：枪口、法杖等跟随动画骨骼；弹道从出手帧正确发射，不再从脚边或错误位置飞出，抛射高度按配置绘制。
- **浮游单元表现**：洛洛、澄闪、耶拉、荒芜拉普兰德等浮游物按技能飞出、攻击和返回，不再被通用光柱替代。
- **持续特效跟随目标**：敌人的光环、护盾、隐匿及灼燃、减速、沉默、脆弱等状态随目标移动，不再留在出怪口或路径上。
- **命中特效重复/延迟**：移除官方特效前后多余的通用闪光、弹道和治疗效果，避免先播通用效果再播官方效果；补齐多名干员直接技能伤害/治疗的官方命中特效。
- **护盾层数显示**：只显示当前护盾层数对应的特效；护盾破碎后清除，天赋光环按技能状态正确隐藏/显示。
- **技能特效重复播放**：缄默德克萨斯登场特效不再随每次普攻重播；仇白剑风按部署朝向显示；余等技能开启特效不再误出现在每次普攻上。
- **特效与模型位置**：修正角色身后光环遮挡人物、线条特效固定在棋盘、蒙皮模型变形、弹体命中后停留等表现问题；野鬃枪尖、铃兰狐尾、溯光星源闪电等位置和方向得到修正。
- **角色眼睛遮罩**：修复纯烬艾雅法拉闭眼时眼球穿过眼皮的问题，并扩展修正到 50 多名使用类似遮罩的干员。
- **阶段与棋盘提示**：修正出怪口/目标框颜色过亮；补充官方回合、阶段、结算和协议启动提示动画。
- **余三技能火墙**：补齐官方火墙表现，按干员朝向连接整条火墙。
- **音效播放**：按官方音库的上限、音高与延迟播放；修复高速攻击时延迟音效不断被替换而整段无声，以及换场/离局后旧战场声音残留。

## 工作台、导入和素材工具

- **外观表单覆盖手写数据**：重开表单读取当前文件，保存只合并表单改动，不再覆盖手写字段、额外干员或隐藏特效配置。
- **素材上传误覆盖**：错误 PNG/Spine、重名皮肤、选图后的异步回调不再覆盖原素材或新参数；上传前检查完整目录，缺图提示不会掩盖新错误。
- **插件检查误报/漏报**：kit DSL 必需权限不再被误判为未使用；插件缺失目标、外观挂载点、脚本权限及冲突报告会给出更具体原因。
- **Forge 导入丢数据**：补充隐藏标记、普通/精锐 id、借用官方干员来源、技能黑板数值和精锐召唤物形态等字段；不能映射的内容明确列入报告。
- **自定义特质和战斗校验**：修复覆盖后的获得特质未触发、最后一张售出奖励未执行、层数增益/冷却精度问题；相关战斗由服务器结算，拒绝伪造层数。
- **PNG 检查兼容性**：允许逐张修复缺图但不新增检查问题；完整处理调色板、16 位和交错 PNG，限制解压后体积，单图损坏不再阻断同包后续导入。
- **插件公告/主题大输入**：过大的公告只跳过自身，不再导致其他公告丢失；主题值长度受限。
- **素材下载错误响应**：不再把 HTTP 40x 当作下载成功；缓存按内容校验，下载失败保留旧文件，避免错误文件进入素材清单。
- **Node 26 代理测试**：修正代理检测与转发兼容性。

## 与当前定制版有关的注意事项

以上是新版更新记录宣称的修复，不代表每项在当前定制版都能直接复现，也不代表已在本机验证通过。新版本仍需迁移当前项目的 6/10 人房、Android、聊天、历史记录、铳跨局限制等定制功能；不能把这份清单理解为这些定制 Bug 也都已修复。

此外，新版中很多条目是大量逐干员的特效、模型和工具细节修复，文档按问题类型归纳，并非逐个角色的穷举清单。完整原始记录见桌面新版的 `CHANGELOG.md`。
