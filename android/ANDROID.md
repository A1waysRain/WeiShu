# 安卓离线 APK

APK 内含游戏的 Node.js 服务端、浏览器客户端和本机已下载的素材。安装后在手机上独立运行，不需要电脑或网络；游戏服务只监听手机的 `127.0.0.1`。首次打开会解压资源到应用私有目录，需要额外约 500 MB 空间，耗时可能数分钟。当前只构建 ARM64 Android 7.0 及以上设备。

## 构建

在项目根目录准备 Node.js 22/24、JDK 17、Android SDK（API 35）、Android NDK、CMake 3.22.1 和 Gradle 8.9 或更新版本，设置 `ANDROID_HOME` 与 `JAVA_HOME`。随后运行：

```bash
npm ci
npm run setup
npm run android
```

构建脚本位于 `android/build-android.mjs`，会下载 `nodejs-mobile-react-native@18.20.4`，提取其 Android ARM64 Node 运行库到被忽略的 `.cache/android/`。Gradle 将项目根目录的 `server/`、`shared/`、`data/`、`public/`、`ws` 和 `android/mobile-entry.mjs` 打成 APK 内的 `game.zip`。产物在 `android/app/build/outputs/apk/debug/app-debug.apk`，可用 `adb install -r` 安装，或传到手机直接安装。生成的是调试签名 APK，不适合直接发布到应用商店。

游戏素材仍受原权利人版权约束，不属于本项目 GPL 代码许可证；请阅读 [NOTICE.md](../NOTICE.md)。本地生成的 APK、运行库和素材都不纳入 Git。

## 使用与限制

- 已结算的历史对局自动保存最近 20 局，可在标题页或大厅点击“历史对局”查看胜负、阵容和统计。安卓使用应用私有存储，重启、更换内置服务端口或联机地址不丢失；卸载或清除数据会删除历史。浏览器版本按访问地址本地保存，清除站点数据会删除历史；远端服务器需更新网页代码才能使用此功能。只保存功能上线后实际参与并收到结算的对局，不保存回放或未结束对局。
- 统计信息在 Android 上保存于应用私有存储，不依赖内置服务每次启动时分配的端口；重启应用后仍可读取。浏览器版统计仍按访问地址保存在 `localStorage`。升级到包含此修复的 APK 后，新产生的统计会跨重启保留；旧 APK 中因端口变化而不可访问的 WebView 统计无法自动找回。卸载或清除应用数据会删除统计信息。
- SakuraFrp 联机使用 `https://dx.frp-bus.com:60330/`（可带房间参数）。应用仅为 `dx.frp-bus.com` 信任随包提供的自签名证书，不覆盖其他域名或子域名；网页和 WSS 联机连接共用 Android 网络安全配置。其他服务器仍使用系统信任的证书，证书错误仍会停止连接。内置证书有效期为 2026-10-05 至 2027-10-05（UTC），连接前会检查有效期；若 frpc 重新生成或更换证书，需要更新 `app/src/main/res/raw/sakura_dx_certificate.pem` 并重新构建 APK。证书来自 frpc 工作目录中的 `dx.frp-bus.com.crt`，仅复制公开证书，私钥 `.key` 不得打包。
- 干员技能与模组配置自动保存在应用私有存储中，关闭后再次打开、内置服务端口变化或切换至新版联机页面时会恢复。浏览器原有配置在读取时自动迁移；卸载应用或清除应用数据会删除配置。远端服务器需更新网页代码，才能读写应用中的共享配置。
- 标题页和大厅的“应用内联机”可粘贴完整 HTTPS 地址（可带 `?room=同盟密钥`），也可使用局域网/虚拟组网地址。连接后直接在应用 WebView 中游玩，不启动外部浏览器。按系统返回键可回到本机游戏，也可在联机窗口选择“返回本机游戏”。HTTPS 服务器需支持 WebSocket 转发，入口应位于域名根路径。
  2026-10-23 已恢复新版网页界面遗漏的入口：标题页登录框和大厅“加入同盟”区域均显示按钮，仅在 Android 原生桥可用时显示。连接远端服务器后，远端网页也需更新到包含此入口的版本才能显示按钮；系统返回键仍可回到本机。
- 手机横屏打开应用即可进入游戏。浏览器版本的触摸部署、长按详情、画质设置和 2D 棋盘回退仍然适用。
- 独立模拟完全本机运行。同盟模拟要和其他玩家联网；离线时可以使用 AI 队友。
- 同一 Wi-Fi 联机：房主在同盟等待室复制邀请链接，另一台设备用浏览器打开，或在 APK 大厅点“连接其他手机”粘贴链接。两台 APK 都可以安装；访客要连接房主地址，不能只在自己的本机房间输入密钥。访客 Wi-Fi 的客户端隔离可能阻止互访。
- 跨网络联机：双方先安装并连接到同一个虚拟局域网（如 Tailscale、ZeroTier），再由房主复制邀请链接（APK 会优先使用检测到的虚拟网卡地址），访客在 APK 大厅粘贴。也可以连接已有的 HTTPS 公网服务器。只有 APK 和房间密钥、没有虚拟组网或公网服务时，手机网络的 NAT 无法被直接穿透。
- 房主手机必须保持应用运行；锁屏、系统省电限制或切换网络可能中断服务。邀请链接中的端口会在重新启动应用后变化，需要重新复制。
- 房间和对局仅保存在进程内。安卓系统杀死应用进程或应用升级后，未结束的对局无法恢复。
- APK 包含完整素材，体积较大。较老的设备可在游戏设置里调低画质。
